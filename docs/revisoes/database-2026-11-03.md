Primeira saída do caminho principal: duas linhas de progresso distintas para Ana e Beto. Arquivos: `Documentos/dados-sql/executar.py` e `aula.sql`. Terminal inicia Python; `sql>` recebe SQL; `.sair` retorna ao terminal. Cada reinício cria uma base em memória nova. Uma recusa interativa imprime a mensagem completa e permite conferir a mesma conexão. O executor não é um parser SQL geral e não deve ser usado em produção.

Grafo principal corrigido:

```text
Etapa 0 / Python / alternativa SQLite
  → modelagem → normalização → DDL → CRUD → SELECT → agregação → JOIN → CTE/view
  → transações → limites/savepoints → projeto SQL
Preparação Docker → Docker básico → Compose → operação/recuperação
  → preparação PostgreSQL → PostgreSQL → projeto de estoque / desempenho
Python dados/exceções → SQLite com Python → funções → segurança
Python arquivos/exceções + SQLite → recuperação → projeto de recuperação
Modelagem + SELECT → modelos NoSQL → preparação MongoDB → CRUD → pipeline (opcional)
```

Não foi necessária troca de IDs ou de ordem de módulos. MariaDB/Firebird/MongoDB continuam no catálogo, com aprofundamento opcional identificado. Competências de Python são atalhos, não exigência de concluir toda a trilha.

Para estudar com foco profissional, use marcos, não só porcentagem:

1. **Fundamentos:** recriar catálogo e escrever consultas novas sem solução; explicar zero, NULL, JOIN e restrições.
2. **Aplicação:** registrar alteração transacional e provar que a falha não deixa meia operação; reconstruir ambiente pelo README.
3. **Operação inicial:** diagnosticar conexão, interpretar plano sem prometer aceleração e restaurar em destino separado.
4. **Desenvolvimento júnior:** integrar banco a API, validação, testes e publicação nas aulas de Entrega. A trilha de dados isolada não cobre toda essa formação.
5. **Avançado ainda requer ampliação:** consultas analíticas/janelas, datas e intervalos, importação/qualidade de dados, isolamento com sessões concorrentes, locks/deadlocks, roles reais, recuperação temporal, desempenho sob carga e decisões operacionais revisadas. Não estão aprovados por esta revisão.
