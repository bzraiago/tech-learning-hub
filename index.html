    RUMO À PRIMEIRA OPORTUNIDADE

    Evidências para atuar como dev júnior

    Registre o que você consegue demonstrar em um repositório e em uma aplicação. Cada marcação é sua autoavaliação; não é certificado nem avaliação automática de empregabilidade.

    Sequência sugerida: HTML e CSS → JavaScript → Git e colaboração → Banco de Dados → Qualidade e manutenção → Integração e entrega. Python e IA ampliam os caminhos possíveis conforme a vaga.

      Próxima etapa da formação: aprofundar os módulos e criar um projeto integrador de portfólio que reúna essas evidências.

      O que demonstrar em cada nível

      Estes são critérios de provas práticas, sem avaliação automática de nível. Para avançar, resolva uma tarefa nova sozinho, mostre o resultado e explique suas decisões. Aulas concluídas, quiz e autoavaliações ajudam a acompanhar o estudo, mas não liberam um nível.

      1. Nível 0 · Preparação

        Crie uma pasta e um arquivo .html com extensão visível; abra no editor e no navegador. No terminal, mostre a pasta atual, execute um comando, registre a saída e copie uma mensagem de erro com contexto. Explique como salvar, executar, observar e encerrar.

      2. Nível 1 · Básico consistente

        Entregue o organizador de estudos responsivo, acessível por teclado e persistente; mostre validação, casos vazios e testes. Inclua histórico Git e README reproduzível, relatório Python sobre JSON e consultas SQLite. Atenda a uma mudança de requisito e explique as escolhas.

      3. Nível 2 · Júnior

        Entregue a plataforma de estudos com interface, API, validação no servidor, PostgreSQL, testes e publicação. Outra pessoa deve reconstruí-la pelo README. Reproduza e corrija um defeito em código existente; implemente um requisito novo em branch e explique a solução.

      4. Nível 3 · Intermediário

        Evolua a plataforma com camadas, migração e transação de banco, autenticação e autorização. Mostre testes de integração e interface, CI executada, logs úteis e uma revisão incorporada de outra pessoa. Demonstre uma falha, a correção e a recuperação.

      5. Nível 4 · Avançado

        Meça um gargalo antes e depois de uma mudança, documente alternativas e custos, aplique uma correção de segurança e reproduza a infraestrutura. Para a extensão de IA real, mostre fontes, abstenção e avaliação com casos de falha. Conduza uma mudança revisada por outra pessoa e explique os riscos restantes.

      Em cada prova, guarde código ou arquivo executável, instruções de reprodução, resultado observado e explicação das decisões. Peça a outra pessoa para conferir; o registro neste navegador é apenas autoavaliação.
