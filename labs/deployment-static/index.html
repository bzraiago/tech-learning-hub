INTEGRAÇÃO & ENTREGA

Seu primeiro deploy sem build

Esta página é composta por HTML e CSS. A Vercel pode publicar estes arquivos sem instalar dependências nem executar uma etapa de compilação.

Ir para as verificações

Arquivos da página

index.html define o conteúdo. styles.css define a apresentação responsiva.

Raiz do projeto

No repositório, a pasta a selecionar como raiz é labs/deployment-static.

Sem dados pessoais

O laboratório não tem login, formulário, API, banco de dados, rastreamento ou segredo.

EVIDÊNCIAS DA PUBLICAÇÃO

O que conferir depois do deploy

  1. Abra a URL pública de produção e confirme que a página aparece.
  2. Na aba Rede do navegador, confira que / e /styles.css retornam sucesso.
  3. Abra a mesma URL começando por http:// e observe se termina em https://.
  4. Redimensione a janela e navegue pelo teclado, inclusive pelo link “Pular para o conteúdo”.

Limite: esta página prova a publicação de arquivos estáticos. Ela não executa uma API e não demonstra persistência de dados.

Exemplo didático sem serviço externo, coleta de dados ou configuração de domínio.
